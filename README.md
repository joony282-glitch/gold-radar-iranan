# Gold Radar Iran v0.9

نسخه اندرویدی رادار صندوق‌های طلای ایران.

## قابلیت‌ها
- دریافت نمادها و اطلاعات قیمت/NAV از API عمومی TSETMC
- محاسبه حباب: `(Price - NAV) / NAV * 100`
- مرتب‌سازی بر اساس حباب
- تنظیم آستانه حباب مثبت و منفی
- اعلان دوره‌ای پس‌زمینه با WorkManager (حداقل فاصله اجرای دوره‌ای اندروید معمولاً ۱۵ دقیقه است)
- رابط فارسی و راست‌به‌چپ
- بدون نیاز به سرور اختصاصی برای هسته رادار

## نکته
داده TSETMC ممکن است هنگام بسته بودن بازار یا اختلال سرویس خالی/ناقص باشد. نمادهای جدید نیز ممکن است قبل از شروع معاملات ثانویه NAV یا قیمت قابل دریافت نداشته باشند.

فهرست اولیه نمادها بر اساس گزارش‌های منتشرشده در مهر ۱۴۰۵ تنظیم شده و باید در نسخه‌های بعدی از خود TSETMC/Fund API به‌صورت خودکار کشف شود.

## ساخت APK با GitHub Actions
فایل `.github/workflows/build-apk.yml` آماده است. بعد از قرار گرفتن فایل‌ها در مخزن، از تب Actions اجرای `Build Android APK` را اجرا کنید و Artifact با نام `gold-radar-debug-apk` را دریافت کنید.

منبع API:
`https://cdn.tsetmc.com/api/`

این پروژه یک ابزار اطلاعاتی است و توصیه سرمایه‌گذاری محسوب نمی‌شود.
